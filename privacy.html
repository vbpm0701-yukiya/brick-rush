Brick Rush ×3 / Brick Rush Uploader

About this application

Brick Rush Uploader is a private tool used only by the owner of the YouTube channel “Brick Rush ×3”. It generates brick-breaker animation videos on the owner's own computer and uploads them to that channel through the YouTube Data API. It is not offered to the public and has no other users.

Brick Rush Uploader は、YouTube チャンネル「Brick Rush ×3」の運営者だけが使う個人用ツールです。運営者自身のパソコンでブロック崩しの動画を作り、YouTube Data API を通じてそのチャンネルに投稿します。一般には提供しておらず、運営者以外の利用者はいません。

Use of YouTube API Services

This application uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

本ツールは YouTube API サービスを利用しています。利用にあたっては YouTube 利用規約に同意したものとみなされます。Google によるデータの取り扱いは Google プライバシーポリシーをご覧ください。

Information we access

  • An OAuth access token for the channel owner's Google account, with permission to upload videos (youtube.upload) and to read basic channel information (youtube.readonly).
  • The channel's ID and title, used only to confirm that videos go to the correct channel.

アクセスするのは、運営者の Google アカウントの認証トークン（動画の投稿と、チャンネル情報の読み取りの権限）と、投稿先を確認するためのチャンネル ID・チャンネル名だけです。

How information is used and stored

  • The token is stored only on the owner's own computer and is used only to upload videos the tool has generated.
  • No personal information about viewers or any other person is collected, stored, or processed.
  • No information is sold, shared with third parties, or used for advertising.
  • No cookies or analytics are used by this tool.

トークンは運営者のパソコンの中だけに保存し、作った動画の投稿にのみ使います。視聴者やほかの人の個人情報は集めません。情報を販売したり、第三者に提供したり、広告に使ったりすることはありません。

Revoking access

Access can be revoked at any time from the Google account's third-party access settings. Deleting the local token file also stops all access.

アクセス許可は、Google アカウントの「サードパーティによるアクセス」設定からいつでも取り消せます。パソコン上のトークンを削除した場合もアクセスは止まります。
